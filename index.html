Strengths

3つの武器

QA・AI・開発の掛け合わせで、品質に多角的にアプローチする。

QA特化の品質設計力

チェックリストに依存しない探索的テストを実践。状態遷移・境界値・例外系の観点からユーザーシナリオを設計し、チーム平均の6倍の不具合を検出。仕様書では見えない品質リスクを顕在化させる。

AIを活用した品質向上

AIエージェントをレビュー工程に導入し、品質・UX・パフォーマンスの複数視点から自動レビューを実現。テスト観点の抜け漏れ削減と、レビュー時間の短縮を同時に達成。

開発視点を持つQA

Next.js/TypeScriptでの個人開発、Vitest/Puppeteerによるテスト自動化を実践。コードを読み書きできるQAとして、開発者と同じ目線で品質に関わる。「テストする人」ではなく「品質をつくる人」として機能する。

PROJECT 01
Live GitHub

WORD DUNGEON

英語学習アプリ / Next.js + TypeScript + Supabase

Next.jsTypeScript SupabaseVitestPuppeteer
課題

英語学習アプリは多数存在するが、単一の学習手段では継続率が低いという共通課題がある。また個人開発では品質設計が後回しになりやすく、機能追加のたびにデグレリスクが増大する。

工夫

クイズ・フラッシュカード・リスニング・スピーキング・ダンジョンRPGなど多彩な学習モードを用意し、飽きずに続けられる設計とした。実用的な反復学習を軸に、ゲーム要素で継続動機を補強。品質面ではVitest + Puppeteerによるテスト自動化で回帰テストを仕組み化。

結果

テスト自動化により機能追加時のデグレを防止し、品質を担保した継続的な開発を実現。要件定義・設計・実装・テストまで一貫した開発プロセスを個人で完遂。

PROJECT 02
GitHub

AI Multi-Agent Review System

AIエージェントによるレビュー自動化 / AI Company

AI AgentQA Design Multi-Agent Architecture
課題

人手によるコードレビューでは観点の偏りが発生し、品質・UX・パフォーマンスといった複数視点を網羅的に検証することが困難。

工夫

開発者／QA／ユーザーのロールを持つAIエージェントを設計し、パースペクティブベースでのレビューを実施。各エージェントが異なる観点（品質・UX・パフォーマンス）からレビューを行い、その結果を統合することでテスト観点の網羅性を担保する仕組みを構築。

結果

テスト観点の抜け漏れを削減し、仕様漏れや不具合の検出精度が向上。レビューの効率化により開発スピードを維持したまま、品質担保の自動化を実現。

PROJECT 03
GitHub

GAS News Bot

ニュース自動配信Bot / Google Apps Script + Discord API

Google Apps ScriptDiscord APIRSS
課題

約30名のコミュニティで情報共有が手動・属人的で、ニュースの共有頻度にばらつきが発生。
